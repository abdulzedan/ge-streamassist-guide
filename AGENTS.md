# Project rules

## Naming

- Use short, ordinary branch names that describe the work, such as
  `model-selection-docs` or `fix-session-handling`.
- Never include AI coding-agent names or branding anywhere in a branch name,
  including prefixes and suffixes.
- Do not add AI coding-agent names, branding, or attribution to commit messages,
  pull request titles or descriptions, documentation, or other authored content.
