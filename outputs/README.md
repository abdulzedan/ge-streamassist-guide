# Captured outputs

Sanitized response samples showing payload shape. Project, session, query,
answer, file and token values may be replaced. Connected-source titles, URLs
and text are omitted. Files ending in `.excerpt.json` are partial JSON by
design.

| File | Example |
|---|---|
| `01-basic-stream-assist.json` | base Stream Assist |
| `04-multi-turn-session.json` | second turn in a session |
| `09-deep-research-plan.json` | research plan |
| `10-deep-research-execute.excerpt.json` | research content kinds |
| `11-web-grounding.excerpt.json` | grounding metadata |
| `13-image-generation.json` | image file reference |
| `14-video-generation.json` | video file reference |
| `15-add-context-file.json` | upload result |
| `16-query-with-files.json` | file question |
| `18-non-streaming-assist.json` | unary Assist |
| `19-skipped-chitchat.json` | skipped turn |
| `20-language-user-metadata.json` | language metadata |
| `24-a2a-message-stream.excerpt.json` | native A2A stream |
| `27-list-session-file-metadata.json` | file metadata list |

These samples are examples, not a compatibility fixture. Use
[chapter 16](../docs/16-verification.md) for the current evidence record.
